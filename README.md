# Biblioteka Gramotek — atlas posiadanych gier

Aktualizacja atlasu: 2026-10-29. Odczyt list źródłowych: 2026-10-19. 1032 unikalnych wpisów Backloggd z 12 wskazanych list; 1155 przypisań do list, w tym 1 ręcznych dodatków użytkownika.

- [Atlas z wyszukiwarką i filtrami](https://rzdulski.github.io/atlas-posiadanych-gier/)
- [Dane JSON](dane.json)
- [Audyt kompletności](audyt.json)
- [Kopia źródłowych list](snapshot-list.json)
- [Profil Gramotek](https://backloggd.com/u/Gramotek/)

Każda gra zachowuje wszystkie listy źródłowe i odsyłacze. Wspólny adres gry jest scalany; różne edycje o różnych adresach pozostają osobno. Zaznaczenie kilku list pozwala wyświetlić sumę lub przecięcie zbiorów. Filtry zapisują się w adresie, który można dodać do zakładek.

Przynależność odzwierciedla listy Gramotek na dzień odczytu oraz oznaczone dodatki użytkownika. Ręczne przypisanie w atlasie nie zmienia listy w serwisie Backloggd. Atlas nie sprawdza niezależnie bieżących licencji ani ofert abonamentowych. Publiczny snapshot zachowuje źródłowe wpisy i osobno ręczne dodatki.

Repozytorium zawiera gotowy pakiet publikacji. GitHub Pages: main, katalog główny. Aktualizacja wymaga ponownego odczytu wskazanych list i przebudowania eksportu w lokalnym projekcie.
